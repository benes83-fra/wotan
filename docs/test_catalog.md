# Test Catalog

This is an overview of the test and example procedures in [`tests/`](../tests/). Each file has one or more procedures with the signature `proc(allocator: mem.Allocator)`. They are called from `main.odin` as `test.<name>(allocator)`. To choose which tests run, comment the calls in `main.odin` in or out.

Wotan needs Odin **dev-2026-11 or newer** (see the [README](../Readme.md#requirements)).

There are three kinds of test:

- **Reference tests** (`*_reference_test`) compare results with values from established libraries. These include QuantLib 1.44, statsmodels 0.13.5, SciPy 1.10, scikit-learn 1.2.1, hmmlearn 0.3.3, pykalman 0.11.2, TA-Lib 0.8.3, NumPy/pandas, PyTorch (float64), and Hugging Face `transformers` / `tokenizers`. The reference values are hard-coded in the test files. Files that start with `// Generated by gen_*.py` were written by a Python generator script; the scripts are not part of the repository.
- **Contract tests** check properties instead of fixed numbers. Examples: gradients against finite differences, bit-identical results across thread counts, save/load round trips, and memory that is fully released.
- **Examples and demos** print results, often next to textbook values. Most of them do not count failures.

Reference and contract tests print `OK` or `FAIL` for each check and end with a summary line. Failed checks are added to a global count, and the program exits with code 1 if any check failed. Almost every test calls `seed_test(#procedure)` first, so its random numbers depend only on its name.

**Markers**

| Marker | Meaning |
|--------|---------|
| 🌐 | Needs network access (Yahoo Finance, Finnhub, GDELT or other HTTP sources) |
| 🖼 | Writes PNG charts to `plots/` |
| 📁 | Reads local data or checkpoint files (see [Required files](#required-files)) |
